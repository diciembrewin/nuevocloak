# Geobloqueo para Argentina 🇦🇷

Este proyecto muestra contenido en **español** para usuarios de **Argentina** y en **inglés** para el resto del mundo.

## 🚀 Funcionalidad

- Usuarios desde **Argentina** → ven la versión en español 🇦🇷
- Usuarios desde **cualquier otro país** → ven la versión en inglés 🇬🇧

## 🛠️ Tecnologías

- PHP
- Vercel (Serverless Functions)
- API de geolocalización (ipapi.co / ipinfo.io)
